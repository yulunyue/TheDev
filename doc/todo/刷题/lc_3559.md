简介
给定一颗有n个节点的无向树，用edges表示，每条边有一个边权，默认值为0，可以重设为1或者2
两个节点u和v之间的路径的代价，是连接它们的所有边的权重之和。
再给定一个二维数组queries，对于每一个queries[i]=[u，v], 计算从节点 ui 到 vi 的路径中，使得路径代价为 奇数 的权重分配方式数量。

返回一个数组 answer，其中 answer[i] 表示第 i 个查询的合法赋值方式数量。

由于答案可能很大，请对每个 answer[i] 取模 10**9 + 7。

注意： 对于每个查询，仅考虑 ui 到 vi 路径上的边，忽略其他边。

2 <= n <= 10**5

分析
先求到query每条路径的边的长度n


f(m,n) 表示有n条边路径，且最后一条边权重设置为m (0<=m<=2) , 代价为奇数的方案

f(n)= f(0,n)+f(2,n)+f(1,n) = 2*f(0,n)+f(1,n)  因为0和2都是偶数等价的
f(1)=2
g(m,n) 表示有n条边路径，最后一条边权重设置为m (0<=m<=2) , 代价为偶数的方案

g(n)= g(0,n)+g(2,n)+g(1,n) = 2*g(0,n)+g(1,n)  因为0和2都是偶数等
g(1)=1
价的

要求的结果即为 
f(0,n)=f(n-1)
f(1,n)=g(n-1)
