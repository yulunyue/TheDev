# 多臂老虎机
## Q/A 
### Q: 多臂老虎机的最优策略问题中，每个老虎机的概率是随机的，所以可能存在多个最优策略，所以在这种情况下，观察奖励是否比观察懊悔更稳定直观
### A: 懊悔比奖励更能区分策略的差异，有更多信息。比如只观察奖励，你会很容易发现随时间衰减的贪婪算法很不错，但其实它是短视和不稳定的策略，很容易陷入局部最优解。雨露均沾的ucb似乎更好，更稳定

### Q: ucb的原理
### A: 保持好奇心，对探索不多的节点多探索，基于霍夫丁(误差率的概率)上界
