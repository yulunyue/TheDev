### 输入
1. 给定 t 个数字数组 A
### 输入限制
``` python
t=len(A)
assert 1 <= len(A) <= 10**4
assert all(2<=len(a)<=500 for a in A)
assert all(all(1<=v<=len(b) for v in b) for a in A)
assert sum(len(a)*len(a) for a in A) <= 2.5*(10**5)
```
### 输出
1. 对于每一个 A[i], 独立的输出一个二维字符串数组B，并且每个字符要么是D，要么是R
### 输出限制
``` python
a = A[i].copy()

assert all(b.count('D')==b.count('R')==len(a)-1 for b in B)
y,x=0,0
for b in B:
    if d in b:
        if d=='D':
            y+=1
        else:
            x+=1
        if x!=y:
            a[y],a[x]=a[x],a[y]
assert a==sorted(A[i])   #即数组递增排序
assert 0 <= len(B) <= 2*len(a)+4
```

#### 考虑DR排列

等价于每一次从数组中取第一个元素放到最后
abcde -> bcdea
即如果数组可以分为两段有序的序列
A1 <= A2 <= A3 <= ... An
An+1 <= An+2 <=  ... An+m
且An+m <= A1
则可以通过n次 DRDR... 使得数组递增排列。

#### 考虑DDRR排列
x,y   abc
!0,0  abc
0,1   bac
0,2   cab
1,2   acb
!2,2
即完成了只对两个相邻元素做交换
所以我们可以每一轮排列，将相邻的两个递减元素变为递增

#### DR排列和DDRR排列的配合

   1. 比较(a[i],a[i+1]),(a[i+2],a[i+3]) ... (a[n-1],a[n])
   2. 如果a[x]<=[x+1]
      1. 则使用DRDR不交换
      2. 否则使用DDRR交换 a[x],a[x+1]

      1. 下一轮比较则为 (a[i+1],a[i+2]),(a[i+3],a[i+4]) ... (a[n-2],a[n-1])
