## 题目简介
[题目链接](https://codeforces.com/problemset/problem/2039/H1)
### 输入
1. 给定 t 个数字数组 A
### 输入限制
``` python
t=len(A)
assert 1 <= len(A) <= 10**4
assert all(2<=len(a)<=500 for a in A)
assert all(all(1<=v<=len(b) for v in b) for a in A)
assert sum(len(a)*len(a) for a in A) <= 2.5*(10**5)
```
### 输出
1. 对于每一个 A[i], 独立的输出一个二维字符串数组B，并且每个字符要么是D，要么是R
### 输出限制
``` python
a = A[i].copy()

assert all(b.count('D')==b.count('R')==len(a)-1 for b in B)
y,x=0,0
for b in B:
    if d in b:
        if d=='D':
            y+=1
        else:
            x+=1
        if x!=y:
            a[y],a[x]=a[x],a[y]
assert a==sorted(A[i])
assert 0 <= len(B) <= 2*len(a)+4
```
