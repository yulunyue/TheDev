## 题目简介
[题目链接](https://codeforces.com/problemset/problem/2039/H1)
有一个 n*n 的地图，和一个长度为 n 的数组 A, 每一轮，张三从地图的左上角 （0, 0） 出发,每次能选择向下【D】或者向右【R】移动一个单元格。张三不能移动到地图外面，所以无论如何张三都会移动到地图的右下角（n，n），并形成一条有 2n-2 个点的路径。对于路径上的每一个点（Xi，Yi），交换数组 A[x]，A[y]。如果数组 A 非递减排序，则游戏结束，否则下一轮继续从左上角（0，0）出发，移动到右下角
### 输入
1. 长度为 n 的数组 A
### 输入限制
``` python
assert 2<=len(A)<=500
assert all(1<=v<=len(A) for v in A)
```
### 输出
1. 输出 k 个长度为 2n-2 的字符串数组B，每个字符要么是 D，要么是 R
### 输出限制
``` python
assert all(b.count('D')==b.count('R')==n-1 for s in B)
for b in B:
   y,x=0,0
   for d in b:
      if d=='D':
         y+=1
      else:
         x+=1
      if x!=y:
         a[y],a[x]=a[x],a[y]
assert a==sorted(A)   #即数组递增排序
assert 0 <= k <= 2*n+4
```
### 分析
#### DR路径
##### 考虑n=4 &nbsp;&nbsp;A=abcd  &nbsp;&nbsp;小明使用DRDRDR的路径
方向|x|y|A
---|---|---|--
-|0|0|abcd
D|0|1|bacd
R|1|1|bacd
D|1|2|bcad
R|2|2|bcad
D|2|3|bcda
R|3|3|bcda

> 排除 x==y 的交换，剩下的依次为 (0,1) (1,2),(2,3) 根据结合律 等价于 (0,3)
> 就是说每一次从 **A** 中取第一个元素放到最后 **abcd** -> **bcda**

###### 如果数组 A 可以分为两段有序的序列，即满足以下三个条件，我们叫做
   1. A<sub>0</sub> <= A<sub>1</sub> <= A<sub>3</sub> <= ... A<sub>m-1</sub>
   2. A<sub>m</sub> <= A<sub>m+1</sub> <= A<sub>m+2</sub><= ... A<sub>n</sub>
   3. A<sub>n</sub> <= A<sub>0</sub>
   
###### 则可以通过**m**次 DR. 使得数组**A**递增排列。并且A<sub>m</sub>为A的最小值

#### DDRR路径
##### 考虑n=3 &nbsp;&nbsp;A=abc  &nbsp;&nbsp;小明使用DDRR的路径

方向|x|y|A
---|---|---|---
-|0|0|abc
D|0|1|bac
D|0|2|cab
R|1|2|cba
R|1|2|cba

##### 可以完成 (i-1, i+1) 的交换

#### 使用DR路径和DDRR路径的组合，非递减排列数组
设 a 最小的元素索引为 j ，且j为奇数，n为偶数
1. 每一轮从i从第二个元素  i=1 开始，每组选两个数。
   1. 序列为 a[0],(a[i],a[i+1]),(a[i+2],a[i+3]) ... (a[n-3],a[n-2]),a[n-1]  
   2. 如果 a[x]<=[x+1] 或者 x+1==j  由于需要一个下降沿，不用交换最小的元素和它左边的元素
      1. 则使用DRDR不交换
   3. 否则
      1. 使用DDRR交换 a[x],a[x+1]
   4. 由于除了DDRR就是DR，每次会将第一个元素，移动到最后一个，其他元素相对不变
      1. 后面n轮序列为:
         1. a[i],(a[i+1],a[i+2]),(a[i+3],a[i+4]) ... (a[n-2],a[n-1]),a[0] i=2
         2. a[i],(a[i+1],a[i+2]),(a[i+3],a[i+4]) ... (a[n-1],a[0]),a[1] i=2
         3. ...  i=n
      2. 最小的元素也会左移一位 j=(j-1)%len(a)
