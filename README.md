”# TheDev
## 这是一个杂乱的项目，承载了一个野生程序员几年在写代码这件事上的挣扎与思考。取名dev是希望它永远正在开发中，只有一个开发分支，不会有release版本。
## 这里有
### 一个Python后端
基于 **tornado** 的1个简洁的Python后端框架，选择它 的原因并不是因为
1. 基于协程的高性能http服务
1. 良好的架构设计(像大多数开源软件，充满很多冗余代码)
只是因为它刚好简单支持**websocket**，方便与前端的实时通信
### 一个简洁的基于typescript前端库
只用了webpack，笔者相信没有vue，没有react，没有anglur，前端的事情也能做的很好很舒服。前端之所以恶心在于js的弱类型，所以有了typescript。当然vue，react，angule也都是不错的东西
### 没有数据库相关代码
因为用json文件也很舒服，但也有在文件读写留了db的口子，希望有朝一日由于业务的性能瓶颈，会使用到db
