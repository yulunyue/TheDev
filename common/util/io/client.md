# Io Client 模块文档

## 文件概述
`client.py` 定义了客户端 IO 类 `Client`，继承自 `Io` 基类，提供网络客户端的基本功能，包括连接管理、数据接收和服务器通信。

## 主要功能

### Client 类
**用途**: 网络客户端实现，处理与服务器的连接和数据通信

**属性**:
- `server: "Io"` - 服务器引用，用于接收消息时回调

**主要方法**:

**运行循环**:
- `run()`: 客户端运行主循环
  - 持续接收服务器数据
  - 数据为空时自动关闭连接
  - 将接收到的数据传递给服务器处理

**套接字初始化**:
- `init_socket()`: 初始化套接字
  - 客户端版本为空实现，连接时直接使用
  - 子类可以重写此方法进行自定义初始化

**连接管理**:
- `connect()`: 连接到服务器
  - 创建套接字
  - 初始化套接字配置
  - 连接到目标地址和端口
- `close()`: 关闭连接
  - 记录关闭日志
  - 停止数据接收

## 使用示例

```python
from common.util.io.client import Client
from common.util.io.server import Server

# 创建服务器
server = Server()
server.set_addr(src_ip="127.0.0.1", src_port=8080)

# 创建客户端
client = Client()
client.set_addr(
    src_ip="127.0.0.1", 
    src_port=8081,
    dst_ip="127.0.0.1",
    dst_port=8080
)
client.server = server  # 设置服务器引用

# 连接到服务器
client.connect()

# 客户端会在单独的线程中运行
# 当服务器发送数据时，client.server.receive_msg() 会被调用
```

## 工作流程
1. **连接建立**: 调用 `connect()` 方法建立与服务器的连接
2. **启动运行**: 调用 `start()` 在新线程中启动运行循环
3. **数据接收**: 持续监听服务器数据，缓冲区大小为 1024 字节
4. **消息处理**: 将接收到的数据传递给服务器的 `receive_msg()` 方法
5. **连接关闭**: 当接收到空数据时，自动关闭连接

## 设计特点
- **异步通信**: 使用独立线程处理数据接收
- **回调机制**: 通过 `server` 引用将消息传递给服务器
- **自动管理**: 连接断开时自动清理资源
- **日志记录**: 提供连接状态的可视化日志

## 修改注意事项
1. 客户端需要设置正确的服务器地址和端口
2. `server` 引用必须在连接前设置，用于消息回调
3. 数据接收是阻塞式的，大文件传输可能需要调整缓冲区大小
4. 连接关闭时会自动记录日志，便于调试
5. 子类可以重写 `init_socket()` 方法添加自定义的套接字配置
6. 错误处理需要由调用者负责，当前实现不处理连接异常
