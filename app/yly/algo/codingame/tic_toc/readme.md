这是一个关于 3 * 3 * 3 * 3 #子棋的 Python ai算法
pk平台 https://www.codingame.com/ide/puzzle/tic-tac-toe
基本流程
    1. 生成当前走法
    2. 走一步
    3. 更新评分
    4. alpha-bate 算法找最优值
    5. 撤销当前走的那一步
    6. 更新评分
    7  回到2 走下一步
