# C5游戏模块测试

本目录包含TheDev项目中C5游戏模块的测试用例。

## 测试文件说明

### 1. `test_c5_basic.py` - 基础功能测试
**功能**: 测试BoardC5类的基础功能，不依赖外部库
**测试范围**:
- 棋盘初始化和重置
- 棋子放置和状态管理
- 坐标转换 (get_yx/get_idx)
- 位置有效性检查
- 不同棋盘大小支持
- 游戏场景模拟
- 边界情况处理

**运行方式**:
```bash
python tests/app/test_c5_basic.py
```

### 2. `test_c5_game.py` - 完整功能测试
**功能**: 测试完整的C5游戏逻辑，包括状态管理和动作系统
**依赖**: 需要pytest和torch等依赖库
**测试范围**:
- StateStatic状态管理
- C5ACtion动作系统
- 游戏流程完整性
- 状态一致性验证

**运行方式**:
```bash
python -m pytest tests/app/test_c5_game.py -v
```

### 3. `test_c5_game_simple.py` - 简化测试版本
**功能**: 不依赖pytest的简化测试版本
**特点**: 使用内置断言，适合快速验证

## 添加新测试

### 测试命名规范
- 测试函数名以 `test_` 开头
- 测试类名以 `Test` 开头
- 测试描述要清晰表达测试目的

### 测试结构
```python
def test_feature_name():
    """测试功能描述"""
    # 1. 准备测试数据
    # 2. 执行测试操作
    # 3. 验证测试结果
    assert condition
```

### 测试原则
1. **单一职责**: 每个测试只测试一个功能点
2. **独立性**: 测试之间不相互依赖
3. **可重复性**: 测试结果应该稳定
4. **清晰性**: 测试代码要易于理解

## 故障排除

### 常见问题

1. **导入错误**
   ```
   ModuleNotFoundError: No module named 'torch'
   ```
   **解决方案**: 使用 `test_c5_basic.py` 进行基础功能测试

2. **路径问题**
   ```
   ImportError: No module named 'app'
   ```
   **解决方案**: 确保在项目根目录下运行测试

3. **依赖缺失**
   ```
   ModuleNotFoundError: No module named 'pytest'
   ```
   **解决方案**: 安装pytest或使用简化测试版本

### 运行建议
1. 首先运行 `test_c5_basic.py` 验证基础功能
2. 如需完整测试，安装依赖后运行 `test_c5_game.py`
3. 定期运行测试确保代码质量
